# Billing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Cadastro, assinatura Premium e painel administrativo com testes de regras financeiras.
**Architecture:** API .NET/PostgreSQL mantém CPF pseudonimizado, benefício e assinatura; Stripe Checkout/Portal e webhook; Next.js renderiza estados e acesso somente leitura separado.
**Tech Stack:** .NET 10, EF Core PostgreSQL, Stripe HTTP API, Next.js 16, React 19.
**Spec:** docs/superpowers/specs/2026-10-26-billing-design.md

## Global Constraints
- BRL 2399 centavos, mensal; trial um mês de calendário, sem repetição por CPF.
- Sem credenciais no cliente, sem mutações na conta Stripe real durante desenvolvimento.
- Manter alterações SEO existentes e arquivos gerados preexistentes da API.

## Review Focus
- Checkout concorrente/crash: chave idempotente persistente, lock por usuário e reconciliação.
- Webhook duplicado/fora de ordem: validar assinatura e consultar estado atual.
- Exclusão/recriação: ledger independente e cancelamento confirmado antes de apagar.
- JWT antigo/acesso direto: autorizar servidor por estado atual.
- Migração/indisponibilidade: feature flag, concessões explícitas e falha fechada.
